Release Notes
=============

The full release history is kept in the
`CHANGELOG <https://github.com/astrochialinko/torchKLIP/blob/main/CHANGELOG.md>`_
on GitHub.

v0.2.0 (2026-10-30)
-------------------

Adds reference differential imaging (RDI) and a hybrid ADI+RDI mode, KLIP
diagnostics (KL eigenimages, PSF models, residuals), multi-planet SNR with
keep-out zones, and new ``torchklip.io`` and ``torchklip.plotting`` modules.

v0.1.0
------

Initial release.
